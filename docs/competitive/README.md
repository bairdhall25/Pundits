# Competitive intelligence

Status: Operational

This directory records products that overlap with Pundits.Pro. It exists to improve product judgment, not to drive reactive feature copying.

## How to use this directory

- Create one Markdown file per competitor.
- Date every researched baseline and follow-up observation.
- Separate verified facts from interpretation.
- Evaluate product quality, data quality, distribution, traction, business model, and team.
- Record partnership potential as well as competitive risk.
- Report meaningful changes; do not treat dependency updates or automated commits as market traction.

## Standard assessment

Each profile should answer:

1. What customer and job does the product target?
2. Who built it, and what team or funding is visible?
3. Is the core product operating reliably?
4. Is the experience compelling to an ordinary sports fan?
5. Does it have distribution, customers, revenue, or credible partnerships?
6. What does it do better and worse than Pundits.Pro?
7. Could it become a supplier, data partner, acquisition target, or distribution partner?
8. What observable changes would alter the current assessment?

## White space (interpretation)

Nobody else currently ships named pundit + verbatim quote + source URL + frozen Kalshi + hit/miss on a CFB/NFL game card. Closest *job*: Cole. Closest *mechanism*: Whose Bet Cashes. Closest *distribution* of expert consensus: Tallysight / Pickwatch / BettingPros. Closest *X receipts culture*: Freezing Cold Takes.

## Monitoring discipline

Threat assessments should be based on demonstrated distribution and operating reliability, not the number of features advertised. Partnership assessments should require clear data rights, complementary assets, dependable delivery, and a lower integration cost than building the capability independently.
